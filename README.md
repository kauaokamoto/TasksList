# Beginner To do list Project

This is a simple task manager system made by a beginner studying Back-End.

## Technologies

- Python 3 (Main language)
- JSON (Data storage)
- Git/GitHub (Version control)

## How it works

- **Add tasks:** You can add tasks and it saves automitically
- **List:** In panel shows the list, an input to write the task and commands you can use.
- **Data:** Your tasks are saved in a JSON file, so you won't lose your records.
- **Comands:** Includes two commands, `/clean` to reset the list and data, and `/stop` to stop to run the program.

## Project Structure

- **List:** Run this file to start the program. It executes the main prompt and executes the function to save.
- **DataManager:** Handles creating and saving Data.

## How to Run

**Clone repository command:**
```bash
git clone https://github.com/kauaokamoto/TaskList.git
```
and run the program.
